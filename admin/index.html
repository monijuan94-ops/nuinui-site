はじめての方へ

この画面は最初の1回だけです。以降はこの端末のブラウザが覚えているので、すぐ書き始められます。

  1. GitHubにログインした状態で こちらのページ を開きます。
  2. Repository access で「Only select repositories」を選び、サイトのリポジトリを選びます。
  3. Permissions → Repository permissions の Contents を Read and write にします。
  4. 一番下の Generate token を押し、表示された github_pat_… という文字列をコピーします。
  5. 下の欄に貼り付けて「保存する」を押してください。

※ トークンはこの端末のブラウザ内にのみ保存され、外部には送信されません。共用のパソコンでは使わないでください。
