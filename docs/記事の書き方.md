# 記事の書き方（工場長・メンバー向け）

お知らせやブログを書くための手引きです。パソコンでもスマホでもできます。

---

## はじめの1回だけ：「合いことば」の設定

記事ダッシュボード（サイトのURLの末尾に `/admin/` をつけたページ）を開くと、
「はじめての設定」という画面が出ます。**この端末では、これが最初の1回きり**です。

画面に3つのステップが出るので、そのとおりに進めてください。

1. **「GitHubのページを開く」ボタンを押す**
   新しいタブでGitHubが開きます。設定はすでに入った状態で開くので、選び直す必要はありません。
   （ログインを求められたら、ぬいふぁくのアカウントでログインしてください）

2. **開いたページで2つだけ操作する**
   - **Expiration（有効期限）** を **No expiration** に変える
     ※「30 days」のままだと1か月で使えなくなり、また設定し直しになります
   - ページの一番下までスクロールして、緑の **Generate token** を押す

3. **出てきた文字を貼り付ける**
   `ghp_` ではじまる長い文字が出るので、コピーしてダッシュボードの欄に貼り、「つなぐ」を押す

「つながりました」と出れば完了です。以降は `/admin/` を開くだけですぐ書けます。

> 💡 この文字は**画面を閉じると二度と表示されません**。すぐに貼り付けてください。
> なくしても、同じ手順でいつでも作り直せます。

> ⚠️ この合いことばは、そのアカウントの全リポジトリを操作できます。
> このサイトだけに限定したい場合は、ダッシュボード下部の
> 「うまくいかないとき／くわしい設定」に、より安全な作り方を書いてあります。

## 記事を書く

1. 上のタブで **お知らせ** か **ブログ** を選ぶ
2. **＋ 新しい記事を書く** を押す
3. 入力する

   | 欄 | 説明 |
   |---|---|
   | タイトル | 記事の見出し |
   | 日付 | 記事に表示される日付 |
   | カテゴリー | お知らせのみ。NEWS / EVENT / VOICE |
   | かんたんな紹介文 | 一覧に出る2〜3行。空でも大丈夫 |
   | カバー写真 | 一覧のサムネイル。「写真を選ぶ」から |
   | 本文 | 自由に書いてください |

4. **公開する** を押す

反映まで **1〜2分** かかります。すぐ見えなくても慌てず、少し待ってから再読み込みしてください。

---

## 写真を入れる

本文の入れたい位置にカーソルを置いて、**画像を入れる** を押し、写真を選ぶだけです。
自動でアップロードされ、本文に差し込まれます。右側のプレビューですぐ確認できます。

> 📱 スマホからでも、カメラロールの写真をそのまま選べます。
> 写真が大きすぎると表示が遅くなるので、**1枚2MB以内**を目安にしてください。

---

## 文字の飾り方

ボタンを押せば自動で入りますが、直接書いても構いません。

| やりたいこと | 書き方 | 表示 |
|---|---|---|
| 大見出し | `## 見出し` | 大きい見出し（ピンクの線つき） |
| 小見出し | `### 見出し` | 小さい見出し |
| 太字 | `**強調したい文字**` | **強調したい文字** |
| リンク | `[表示する文字](https://…)` | リンク |
| 箇条書き | 行頭に `- ` | ・のリスト |
| 引用 | 行頭に `> ` | 縦線つきの引用 |

**段落を分けたいときは、空の行を1行はさんでください。**

---

## 下書きにしておく

まだ公開したくないときは **下書き保存** を押します。
下書きはサイトには出ません。あとで開いて続きを書き、「公開する」を押せば公開されます。

公開済みの記事を下書きに戻すこともできます（サイトから消えます）。

---

## よくある質問

**Q. まちがえて公開してしまった**
その記事を開いて「下書き保存」を押せば、サイトから消えます。

**Q. 記事を消したい**
記事を開いて「削除」を押します。もとには戻せません（※GitHubの履歴には残ります）。

**Q. 書いている途中でブラウザを閉じてしまった**
保存前の内容は残りません。長い記事はときどき「下書き保存」を押してください。

**Q. トークンってなに？危なくない？**
「このリポジトリの中身だけ書き換えていいですよ」という許可証です。
サイトのファイル以外は触れません。ただし**共用のパソコンでは使わないでください**。
使い終わったら右上の「ログアウト」で消せます。
