# こまったときは

---

## ダッシュボードが使えないとき

### 「トークンが正しくないようです」と出る

トークンには**有効期限**があります（作成時に指定）。期限が切れたら作り直してください。
右上「ログアウト」→ 再度トークンを貼り付ければ復旧します。

### 「権限が足りません」と出る

トークンの **Contents** が **Read and write** になっていません。作り直してください。

### 画面が真っ白・ボタンが反応しない

ブラウザを再読み込み（スマホは一度タブを閉じて開き直す）してください。
それでも直らない場合は下の「非常口」へ。

---

## 非常口：ダッシュボードを使わずに記事を直す

**ダッシュボードが完全に壊れても、サイトの更新は止まりません。**

1. GitHubでリポジトリを開く
2. `content/news.json`（または `blog.json`）を開いて鉛筆アイコンで編集
3. 記事の `body` を書き換えて Commit
4. `news/<slug>.html` の中身も同じように直す

JSONは記事の「正本」、HTMLは「表示用のコピー」です。両方直せば反映されます。
面倒なら、**AIに「このリポジトリの○○という記事を直して」と頼むのが確実です。**

---

## サイト全体が表示されなくなった

### まず確認

- GitHub の **Settings → Pages** で公開設定が消えていないか
- リポジトリが Private になっていないか（Publicでないと無料公開できません）
- 独自ドメインを使っている場合、`CNAME` ファイルが消えていないか

### 直前の変更で壊れた場合

GitHubの **Commits**（履歴）から、壊れる前のコミットを開き、
`Revert` を押せばその変更だけを取り消せます。**全履歴が残っているので必ず戻せます。**

---

## 手元にバックアップを取る

年に数回でよいので、リポジトリ全体をダウンロードして保管してください。

1. GitHubのリポジトリ画面 → 緑の **Code** ボタン → **Download ZIP**
2. ZIPをGoogle DriveなどにアップロードするかUSBに保存

これがあれば、GitHubに何かあってもサイトを丸ごと復元できます。

---

## 引き継ぎたいとき

`docs/アカウント台帳.md` に、必要なアカウントの一覧があります。
新しい担当者には次の3つを渡してください。

1. リポジトリへの権限（Settings → Collaborators から追加）
2. `docs/アカウント台帳.md`
3. このフォルダの `README.md` と `docs/` 一式

技術的な引き継ぎは、AIに `README.md` と `CLAUDE.md` を読ませるのがいちばん早いです。
